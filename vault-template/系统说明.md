# 系统说明

一句话：**手表记录 → 手机每小时自动导出 → 数据到 Mac → 腕康宝每个整点检查 → 今天的笔记实时更新 → 过完一天定稿。**

## 这个库里有什么

| 文件 / 文件夹 | 谁写 | 说明 |
|---|---|---|
| [[个人档案]] | 你 | 身高体重、目标、食谱、训练日、调整规则。AI 每次都读 |
| [[手动记录]] | 你 | 体重、多吃 / 少吃、InBody、力量训练表 |
| [[训练计划]] | 你 | 示例训练计划，换成你自己的 |
| 每日/日期.md | 腕康宝 | 每日笔记：上面的数字 + 「备注」（你写）+ AI 报告 |
| 每周/YYYY-Www.md | 腕康宝 | 每周一写上周的周报 |
| 模板/每日模板.md | — | 新建每日笔记用的模板 |

## 你要做的

| 什么时候 | 做什么 |
|---|---|
| 平时 | 正常用手机，什么都不用点 |
| 看报告时 | 醒着时「数据截至」比现在早 3 小时以上 → Health Auto Export → 手动导出 |
| 每天起床 | 称体重，填进[[手动记录]] |
| 吃得和食谱不一样 | 在[[手动记录]]「多吃 / 少吃」写一句大白话 |
| InBody 日 | 填体脂率、肌肉量、内脏脂肪 |
| 训练日练完 | 在[[手动记录]]的力量训练表填重量和每组次数 |
| 睡觉 | 戴着手表（睡前充到 30% 以上） |

## 每日报告长什么样

- 一句话结论
- 状态总览：睡眠 / 恢复 / 活动 / 能量 / 体成分，🟢🟡🔴⚪，跟你自己最近 28 天的正常范围比
- 问题清单：每条写「发现 → 解读 → 怎么做」
- 其他指标、今天可以做得更好、明天的处方、什么时候该看医生

示例见仓库里的 examples/demo-vault/每日/2026-01-04.md（数据是虚构的）。

> 报告由 AI 根据手表数据生成，仅供参考，不能代替医生诊断。
